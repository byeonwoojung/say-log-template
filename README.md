# say-log-template

> 말하면 기록되는 나만의 AI 기록 앱 · 출발 템플릿

## 개요

| 항목 | 내용 |
|---|---|
| 대상 | 코딩을 몰라도 되는 **비전공자** |
| 만드는 것 | 말하면 기록되는 **나만의 기록 앱** (폰 설치) |
| 들어 있는 것 | 기록 앱 **기본 화면** (`public/`) |
| 진행 방식 | Claude와 **대화로 직접 정하고** 만들기 |

## 준비물

- 노트북 (윈도우 · 맥)
- 스마트폰
- Claude 유료 구독 (Pro 이상)
- Claude 데스크톱 앱 설치 · 로그인 → [claude.com/download](https://claude.com/download)

## 시작하기

1. Claude 데스크톱 → **Code** 탭 → **빈 폴더** 열기
2. 시작 문장 보내기

   ```
   https://github.com/byeonwoojung/say-log-template 를 이 폴더에 내려받고 README를 읽어줘.
   ```

3. 이후 → **내 말로** 진행

## 큰 단계

| 단계 | 핵심 | 결과 |
|---|---|---|
| **1. 준비** | 템플릿 · 개발 도구 · 기본 앱 실행 | 내 컴퓨터에서 기본 앱 실행 |
| **2. 계획** | 무엇을 만들지 · 어떤 순서로 | `PLAN.md` · `CLAUDE.md` |
| **3. 만들기** | 화면 · 서버·저장소 · API 키·배포 · Claude 연결 | 폰 설치 · 말하면 기록 |
| **4. 꾸미기·키우기** | 디자인 · 기능 추가 · 재배포 | 나만의 앱 · 혼자 계속 고치기 |

- 정해진 질문 X → **하고 싶은 걸 Claude에게 이야기**하며 진행
- 상세 설명 → 세션 자료(PPT)

**기술 결정** (참가자와 정할 필요 없이 그대로 지킬 것)

| 항목 | 결정 |
|---|---|
| 내려받기 | 템플릿의 git 기록 삭제 → `git init` (원본 레포와 연결 끊기) |
| 작업 위치 | **로컬 작업** · 이 폴더에서 바로 작업 · worktree·브랜치·PR X |
| git | **기록용으로만** 사용 (저장 지점·되돌리기) · 원격 연결·푸시 X |
| Node.js | **24 이상 LTS의 최신 버전** · 설치 전 nodejs.org에서 최신 보안 패치 확인 · 20 이하는 쓰지 않기 (지원 종료) |
| 기록 항목 | 공통 칸 `date` `time` `category` `memo` 유지 · 주제별 항목은 `data` 객체 |
| 저장 교체 | `storage.js`만 교체 · 맨 위 주석의 약속(최신순 정렬, `YYYY-MM-DD`) 지키기 |
| 폰 설치 주소 | API 키는 **경로**에: `/k/<API키>/` · 쿼리(`?key=`) X → 설치한 앱에서 키가 사라짐 |
| 커넥터 | 모르는 주소는 404 · 특히 `/.well-known/*` → 앱 화면(HTML)이 나오면 등록 실패 |
| 로그 | `wrangler tail` 등 요청 주소가 찍히는 로그 X → 주소 안 API 키 노출 |
| 비밀 파일 | `.api-key.txt` `.dev.vars` `.env`는 git 제외 (템플릿 `.gitignore`에 포함) |

## 참고

### 파일

| 파일 | 역할 |
|---|---|
| `public/index.html` | 화면 구조 |
| `public/style.css` | 디자인 · 맨 위 **디자인 토큰**(색·글꼴·모서리·간격) |
| `public/app.js` | 기록 추가·수정·삭제 · 달력 · CSV 내보내기 · 앱 설치 버튼 |
| `public/storage.js` | 저장 담당 (현재: 브라우저) |
| `public/manifest.webmanifest` | 폰 설치 정보 (이름·아이콘·색) |
| `public/sw.js` | 폰 설치용 · 캐시 없음 (재배포 즉시 반영) |
| `public/icons/` | 앱 아이콘 |

### 실행

```bash
npx serve public   # → http://localhost:3000 (Node.js 필요)
```
